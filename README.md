## Objetivo
El objetivo del Trabajo Práctico Integrador es desarrollar una aplicación de chat en tiempo real similar a
WhatsApp, integrando todos los temas vistos durante el año: Next.js y React, Node.js, MySQL y WebSockets
(Socket.IO).  
La idea es que el usuario pueda iniciar sesión/registrarse, crear chats tanto inidividuales como grupales y poder interactuar en simultáneo

## Métodos utilizados 
- **Frontend:** Next.js + React
- **Backend:** Node.js
- **Base de datos:** MySQL
- **Comunicación en tiempo real:** Socket.IO / WebSockets
- **Estilos:** CSS
- **Control de versiones:** Git + GitHub
